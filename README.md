# Italy DSU & ISEE Parificato Calculator 🇮🇹🎓

A C++ command-line application designed to help international students calculate their **ISEE Parificato** and **ISPE** scores to determine eligibility for Italian Regional Scholarships (DSU - Diritto allo Studio Universitario), such as DiSCo Lazio, EDISU, and DSU Toscana.

## 🚀 The Problem It Solves
International students applying for public universities in Italy often struggle to understand if their family income qualifies for the DSU scholarship. Calculating the exact ISEE equivalent manually is complex because it involves an equivalence scale based on family size and partial asset weighting. 

This tool automates the process by implementing the official Italian equivalence scale algorithm, allowing students to instantly check their eligibility status.

## 🛠️ Features
- **Object-Oriented Design**: Built using C++ classes for clean architecture.
- **Accurate Equivalence Scale**: Uses the official standard (1 member = 1.0, 2 = 1.57, etc.).
- **Automated Eligibility Check**: Compares results against current standard limits (ISEE < €26,306, ISPE < €57,187).
- **Input Validation**: Prevents invalid or negative data entries.
